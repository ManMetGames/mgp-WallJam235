# MGP_2526
 The assessment repo for 2526
 ## Downloading Guide
 1. Select the drop down arrow on the green Code button and select "Download Zip"
    <img width="538" height="348" alt="image" src="https://github.com/user-attachments/assets/29ac37df-1b26-4163-8ce7-ddd8123b43a7" />
 2. Extract the zip to a folder of your choosing (it is not recommended to put this into a OneDrive folder due to potential performance issues)
 3. Right click on the .uproject file and select "Generate Visual Studio Project files" from the menu
<img width="315" height="152" alt="image" src="https://github.com/user-attachments/assets/2a7507bc-9b77-4039-b557-0ab665d76ad8" />
 3a. After generating the files you may receive a prompt asking to rebuild any missing modules in the project, please select "Yes" for this
<img width="424" height="211" alt="image" src="https://github.com/user-attachments/assets/787673be-d89e-41a9-9049-611f9c6e9ebf" />
 4. Success!
    
 ## Controls
 - Use the Mouse to move the camera
 - W,A,S,D to move the player character
 - Space bar to jump
 - Left Shift to sprint
 - Hold Left Click to grapple to a nearby target in the direction you are looking
 - Hold Right Click to reel yourself in towards your grapple (Can only be used while grappling)
